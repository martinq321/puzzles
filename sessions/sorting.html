Mystery-weight boxes

Compare two boxes at a time. Arrange them from lightest to heaviest without seeing their weights.

Tap two box letters, then compare. Use the arrows to rearrange your proposed order. A box’s size does not reveal its weight.

Comparison notebook
    After your own method: explore algorithms

    Both methods below start with the same original arrangement and weights as your puzzle. Each step makes one weight comparison; rearrangement does not count as a comparison.

    Try it with actual boxes

    Use identical closed boxes or opaque cups containing different amounts of rice. Label A–F. Compare on a balance without revealing numerical weights. If using digital scales, the tutor can read the values and report only which is heavier.

    First invent a method. Then try repeatedly selecting the lightest, or inserting each new box into an already ordered group. Return to the same starting arrangement for a fair comparison. Count comparisons separately from movements.
