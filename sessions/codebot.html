Block-path robot

Build a sequence of instructions. Collect every star and finish on the gold tile. Predict the route before pressing Run.

Your program

    Editing resets the robot. Turns rotate on the spot; forward moves one tile in the direction faced. Up to 40 blocks and 500 expanded steps.

    Try it away from the screen

    Lay floor tiles or paper squares, use a toy as the robot and write arrow instruction cards. One person programs; the other follows exactly. Introduce repeated instructions, then repeated sequences. Compare programs that achieve the same route.

    This original five-challenge starter is designed to grow into a richer coding environment with nested loops, conditions, functions and editable worlds. Those features are not implemented yet.

    Design reference: Google’s Coding for Carrots, made with Blockly and the Scratch team. This page uses original code and artwork.
