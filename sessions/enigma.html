Enigma explorer

Type a message and watch the rotors change. Use the same starting settings to recover the original message.

Three-rotor model, reflector B. Settings are left → right. Spaces and punctuation are preserved without stepping. Every edit reprocesses the message from the starting windows.

Trace a letter

The route goes through the plugboard and right-to-left rotors, reaches the reflector, then returns through the inverse wirings to the lamp.

Investigate the mechanism

Type the same letter repeatedly. Why does the output change? Can any letter encrypt to itself? Change one starting window and compare the messages.

The right rotor steps before each letter. Turnover can advance its neighbour; the middle rotor can step on consecutive keypresses. Try starting at ADU with rotors I, II, III and type three letters: the windows become ADV, AEW, BFX.

Make two paper alphabet discs first to revisit Caesar substitution. Enigma adds changing permutations, a return route and state. This is an educational simulator of the selected model, not a modern secure messaging service.
