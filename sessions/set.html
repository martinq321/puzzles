Maths Wednesdays · Make, play, investigate

Find a SET

Choose three cards. For each attribute separately, the three must be all the same or all different.

Start together with nine homemade cards. There is no timer. Touch a selected card again to deselect it.

Make it with cards · teaching notes

For the small deck, draw one of each combination of three shapes and three colours. Use a colour-name label or different pen patterns if helpful. Two cards determine a unique third: for each attribute, keep the value if the first two agree; otherwise use the remaining third value.

Begin by completing pairs, then find triples in the whole deck. For 27 cards add one, two or three symbols; for 81 add open, striped or solid shading. Printed labels identify every attribute so colour is not the only cue.

Extension: if you change the rules, does every pair still determine a unique completing card?

Take your time. Explain a choice. Try a variation.
