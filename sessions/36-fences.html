For educators

This version uses unit fence sections on a square grid: no diagonal or curved edges. A valid design is one closed, connected boundary without branches. The enclosure area counts whole grid cells. The source also invites broader choices of permitted shapes; a grid result does not establish the best shape among all possible polygons.

Start with the physical materials. Use the screen to inspect, compare or test a prediction. Keep one worthwhile question going; there is no timer or compulsory sequence.
