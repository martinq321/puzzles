Can straight strings make a curve?

Tap a nail on one axis, then a nail on the other. Or add the pattern one string at a time.

Try it

Try 1 → 12, then 2 → 11. Predict the next pair. Where is the curve, if every string is straight?

Make it with your hands

Use squared paper and a ruler, or numbered holes in card with wool. Put nails at integer positions on two perpendicular axes. With N = 12, the matching numbers add to 13. Let Jamie make a few pairs before adding more.

For actual nails, an adult prepares the board. Card holes and blunt lacing needles make an alternative.

What shape is it?

The usual equal-step, reverse-order pattern has a parabolic envelope, not a hyperbola. With C = N + 1, a continuous family joins (a, 0) to (0, C − a). Its envelope is x = C t², y = C(1 − t)². Only a finite part is touched by the displayed strings. Finite strings suggest this curve; they do not form a smooth curve themselves.
